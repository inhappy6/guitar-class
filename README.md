# 기타 수업 전체

Canva에서 저장한 49쪽 인쇄용 PDF를 바탕으로 만든 수업 홈페이지입니다. 기초 수업 9개와 8곡의 악보 36구간을 담았습니다.

## 열기

1. [index.html](./index.html)을 열어 **Download raw file**로 내려받습니다.
2. 파일을 Chrome, Edge, Safari 등에서 엽니다. 악보 이미지가 HTML에 포함되어 별도 설치나 인터넷 연결이 필요하지 않습니다.
3. 곡 제목이나 가수 이름을 검색하고, 악보를 열어 이전·다음 버튼으로 이동하거나 200%까지 확대합니다.

이 저장소는 비공개이며 GitHub Pages로 배포되지 않았습니다.
